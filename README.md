# DoTogether

**Get things done, together.**

DoTogether is a collaborative task and schedule management application designed for individuals and teams.

It provides a simple way to manage personal tasks, share work with teammates, and coordinate projects across different departments — all within a unified workspace.

## Core Features (MVP)

- **Personal Task Management:** Create and manage individual projects with descriptions, start dates, and deadlines.
- **Team Collaboration:** Invite other users to collaborate on shared projects and work items.
- **Cross-Team Collaboration:** Support collaboration between members of different departments.
- **Collaboration Invitations:** Send invitations and manage acceptance or rejection requests.
- **Access Control:** Assign collaboration roles to manage access to shared work.
- **Deadline Management:** Request deadline extensions with a reason and track their approval status.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI, SQLAlchemy
- **Database:** PostgreSQL
- **Authentication:** JWT
